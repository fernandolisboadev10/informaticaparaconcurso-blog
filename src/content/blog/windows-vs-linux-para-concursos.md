## O que é o Windows

Antes de comparar os dois sistemas, vale entender a origem de cada um, porque a banca costuma perguntar isso diretamente.

O Windows nasceu em 1985, quando a Microsoft lançou sua primeira versão como uma interface gráfica que rodava sobre o MS-DOS. Bill Gates e Paul Allen fundaram a Microsoft em 1975, e o Windows se tornou, décadas depois, o sistema operacional mais usado em computadores pessoais no mundo. Segundo o Statcounter, levantamento independente que acompanha a fatia de mercado dos sistemas operacionais no mundo, o Windows ainda lidera com folga o uso em desktops, embora o Linux venha crescendo ano a ano.

Atualmente, o Windows funciona como um software proprietário. Isso significa que a [Microsoft](https://www.microsoft.com/pt-br/windows) detém o código-fonte, controla as atualizações e cobra uma licença para o usuário instalar e utilizar o sistema legalmente. Para concursos, esse é o primeiro ponto que você precisa guardar: Windows é sinônimo de sistema fechado e comercial.

## O que é o Linux

O Linux segue uma lógica bem diferente desde a raiz. Em 1991, o finlandês Linus Torvalds criou o [kernel Linux](https://www.kernel.org/) como um projeto pessoal e o distribuiu gratuitamente pela internet, convidando outros programadores a melhorá-lo.

Diferente do Windows, o Linux é um software livre e de código aberto. Isso quer dizer que qualquer pessoa pode consultar, modificar e redistribuir o código-fonte, respeitando a licença [GPL (GNU General Public License)](https://www.gnu.org/licenses/gpl-3.0.html), que rege a distribuição do kernel.

Por isso, quando você ouve falar em Linux, é essencial lembrar que ele é apenas o kernel, o núcleo do sistema. As distribuições (ou distros), como Ubuntu, Debian e Fedora, reúnem esse kernel a outros programas e formam o sistema operacional completo que o usuário instala.

## Arquitetura e código-fonte

Aqui está um ponto que costuma confundir o candidato na prova: arquitetura fechada não significa sistema fraco, e arquitetura aberta não significa sistema instável. São só modelos de desenvolvimento diferentes.

### Windows: sistema fechado e proprietário

No Windows, apenas a equipe da Microsoft acessa o código-fonte original. O usuário comum recebe apenas o produto pronto, compilado, sem possibilidade de auditar ou alterar o funcionamento interno do sistema. Esse modelo garante um padrão único de interface e compatibilidade, mas também concentra na Microsoft toda a responsabilidade por correções e atualizações.

### Linux: sistema aberto e livre

No Linux, a comunidade de desenvolvedores mantém o código aberto ao público em repositórios como o kernel.org. Qualquer programador consegue estudar, sugerir mudanças ou até criar sua própria distribuição a partir do código original. Essa transparência costuma aparecer nas provas como uma das principais vantagens do modelo de software livre.

## Distribuições e versões

Enquanto o Windows lança poucas versões numeradas ao longo dos anos, o Linux se multiplica em dezenas de distribuições diferentes. Entenda por quê.

### Principais versões do Windows

O Windows evoluiu de forma linear: XP, Vista, 7, 8, 10 e, mais recentemente, o Windows 11, lançado em 2021. Além das versões voltadas ao usuário final, a Microsoft mantém o Windows Server, direcionado à administração de redes e servidores corporativos.

### Principais distribuições Linux

Já o Linux se ramifica em famílias de distribuições. A empresa Canonical mantém o [Ubuntu](https://ubuntu.com/), uma das portas de entrada mais comuns para quem começa no sistema. O Debian, base do Ubuntu, ganhou fama pela estabilidade em servidores. A Red Hat patrocina o Fedora, que funciona como uma espécie de laboratório de tecnologias que depois chegam ao Red Hat Enterprise Linux. Já o Kali Linux se destaca em testes de segurança e aparece bastante em questões sobre pentest. O [DistroWatch](https://distrowatch.com/), portal que acompanha o ranking de popularidade das distribuições, é uma boa referência para quem quer visualizar essa disputa em números.

Guarde esta ideia: cada distribuição usa o mesmo kernel Linux, mas escolhe pacotes, interface gráfica e filosofia próprios.

## Comandos e atalhos no Windows

Na prova, os comandos do Windows aparecem tanto no Prompt de Comando (CMD) quanto nos atalhos de teclado do dia a dia. Veja os que mais caem:

**Atalhos de teclado:**

-   Ctrl + C / Ctrl + V: copiar e colar
-   Ctrl + Alt + Del: abre o Gerenciador de Tarefas ou a tela de segurança
-   Windows + E: abre o Explorador de Arquivos
-   Windows + L: bloqueia a estação de trabalho
-   Alt + Tab: alterna entre janelas abertas
-   Windows + D: minimiza todas as janelas e mostra a área de trabalho

**Comandos do Prompt de Comando (CMD):**

-   `dir`: lista arquivos e pastas do diretório atual
-   `cd`: muda de diretório
-   `copy` e `move`: copiam ou movem arquivos
-   `del`: apaga arquivos
-   `ipconfig`: exibe as configurações de rede
-   `tasklist` e `taskkill`: listam e encerram processos em execução

Se a banca afirmar que o comando `dir` serve para apagar arquivos, desconfie na hora: essa é uma pegadinha clássica que troca a função de comandos parecidos.

## Comandos e atalhos no Linux

No Linux, o terminal ocupa um espaço muito maior do dia a dia do que no Windows, e por isso a banca cobra bastante comando de texto.

**Atalhos de teclado:**

-   Ctrl + Alt + T: abre um terminal na maioria das distribuições com interface gráfica
-   Ctrl + C: interrompe a execução de um comando em andamento
-   Ctrl + D: encerra a sessão do terminal
-   Ctrl + Z: suspende o processo em execução
-   Alt + Tab: alterna entre janelas, assim como no Windows

**Comandos essenciais do terminal:**

-   `ls`: lista arquivos e pastas do diretório atual
-   `cd`: muda de diretório, exatamente como no Windows
-   `pwd`: mostra o caminho completo do diretório atual
-   `mkdir` e `rmdir`: criam e removem pastas
-   `chmod`: altera as permissões de um arquivo ou pasta
-   `grep`: busca um padrão de texto dentro de arquivos
-   `sudo`: executa um comando com privilégios de administrador

Não confunda os dois conceitos: no Windows, o usuário Administrador já concentra privilégios elevados por padrão em muitos casos; no Linux, mesmo o usuário root normalmente evita operar direto, e o comando `sudo` concede privilégio temporário só para aquele comando específico. Essa diferença de filosofia de segurança é um ponto que a banca adora explorar.

## Pacote Office em cada sistema

O pacote de escritório é outro ponto de comparação certo em prova, principalmente porque o comportamento dos arquivos muda entre os dois ambientes.

### Microsoft Office no Windows

O Microsoft Office reúne Word, Excel, PowerPoint e Outlook como aplicativos nativos do Windows, embora também rode no macOS. A Microsoft cobra pela licença, seja por meio de uma compra única (Office 2021, por exemplo) ou por assinatura mensal do Microsoft 365, que inclui atualizações contínuas e espaço em nuvem no OneDrive.

### LibreOffice e alternativas no Linux

Nas distribuições Linux, o [LibreOffice](https://www.libreoffice.org/) normalmente já vem pré-instalado e oferece equivalentes gratuitos ao Word (Writer), Excel (Calc) e PowerPoint (Impress). A The Document Foundation mantém esse pacote e o distribui sob licença de software livre.

Aqui está um detalhe que cai bastante: o LibreOffice consegue abrir e salvar arquivos .docx e .xlsx, mas a compatibilidade não chega a 100%. Formatações mais complexas, como macros em VBA, podem se perder na conversão entre os dois pacotes. Memorize este ponto, porque questões sobre interoperabilidade de formatos são recorrentes.

## Pegadinhas mais cobradas em prova

Bancas como o Cebraspe costumam usar palavras absolutas como “sempre”, “somente” e “exclusivamente” para transformar uma afirmação correta em errada. Fique atento quando o enunciado disser algo como “o Linux é sempre gratuito” ou “o Windows é exclusivamente proprietário e nunca tem componentes de código aberto”, porque as duas afirmações têm exceções.

Por exemplo, existem distribuições Linux com suporte pago, como o Red Hat Enterprise Linux, e o próprio Windows incorpora componentes de código aberto em partes específicas do sistema, como o Windows Subsystem for Linux (WSL). Por isso, generalizações fechadas costumam ser a armadilha, não a regra.

Outro erro comum é confundir “sistema operacional livre” com “sistema operacional grátis”. Nem todo software gratuito é livre, já que é possível usar sem pagar mas sem acesso ao código-fonte, e alguns softwares livres têm distribuições comerciais pagas, com suporte incluso. Guarde essa distinção, porque ela aparece disfarçada em várias questões.

## Conclusão

Depois de comparar arquitetura, comandos, atalhos e pacote de escritório, fica mais fácil entender por que a banca gosta de misturar Windows e Linux na mesma questão: os dois sistemas resolvem o mesmo problema de formas opostas, um fechado e comercial, outro aberto e comunitário.

## Perguntas frequentes

### Qual é a principal diferença entre Windows e Linux?

_A principal diferença está no modelo de licenciamento e na arquitetura do código-fonte. O Windows é proprietário: a Microsoft controla o código e cobra pela licença. Já o Linux é livre e de código aberto, distribuído sob a licença GPL, o que permite consultar e modificar o sistema livremente._

### O Linux é realmente gratuito?

_Na maioria dos casos, sim. O download e o uso das principais distribuições, como Ubuntu e Debian, não custam nada. No entanto, empresas como a Red Hat cobram por serviços de suporte técnico sobre suas distribuições, então nem toda solução em torno do Linux é gratuita._

### O que é uma distribuição Linux?

_Uma distribuição, ou distro, é o conjunto formado pelo kernel Linux mais outros programas, como interface gráfica, gerenciador de pacotes e aplicativos. Ubuntu, Debian, Fedora e Kali Linux são exemplos de distribuições que usam o mesmo kernel, mas se diferenciam na escolha de pacotes e no público-alvo._

### O Windows tem componentes de código aberto?

_Sim, e essa é uma pegadinha comum em prova. O Windows incorpora recursos como o WSL (Windows Subsystem for Linux), que permite executar um ambiente Linux dentro do próprio Windows. Por isso, cuidado com enunciados que afirmam que o Windows é “exclusivamente” fechado, sem qualquer componente aberto._

### O LibreOffice consegue abrir arquivos do Microsoft Office sem problemas?

_Consegue abrir e salvar arquivos .docx e .xlsx, mas a compatibilidade não é perfeita. Formatações mais complexas, como macros em VBA, podem apresentar problemas na conversão entre os dois pacotes. Esse é um detalhe que a banca gosta de explorar em questões sobre interoperabilidade._

### Por que a banca costuma comparar Windows e Linux na mesma questão?

_Porque os dois sistemas resolvem o mesmo problema de formas opostas, um fechado e comercial, outro aberto e comunitário. Ao colocar os dois lado a lado, a banca consegue testar se você entende os conceitos de licenciamento, arquitetura e comandos de cada sistema, e não apenas memoriza informações isoladas._
