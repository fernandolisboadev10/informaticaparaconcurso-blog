# informaticaparaconcurso.com.br

Blog Informática para Concurso, feito em Astro e publicado no GitHub Pages. Migrado do WordPress.

```bash
npm install
npm run dev      # servidor local
npm run build    # gera dist/
npm run migrate  # baixa posts, páginas e mídia do WordPress (informaticaparaconcurso.com.br)
```

O arquivo `public/CNAME` aponta para `informaticaparaconcurso.com.br`.
